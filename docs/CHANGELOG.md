# 版本记录

## 0.4 · 2026-10-25

- 新增独立案例 `tianlan-385a-american`：豪华美式家具、材料与装饰设计方案。
- 原样板间案例保留；新的家具、饰面、灯具和地毯不标称实拍复刻。
- 保持户型和独立书房关系，为两个案例分别检查全部房间通行与书房/卫生间隔离。
- 可通过独立链接或空间档案选择器切换案例。

## 0.3.1 · 2026-10-25

- 根据用户实地参观确认，将北东独立房修正为书房；移除床与床头柜，加入示意书桌、书柜和座椅。
- 核对书房经公共走廊独立进入，卫生间北墙、东墙均为实体隔墙，无直通门；增加隔离关系回归检查。
- 房间菜单和现有模型布局标注同步为 3 卧 1 书房。原营销图的 3 厅 4 房标签保留在来源中，书房具体陈设尚未取得实拍。

## 0.3 · 2026-10-25

- 接回此前中断留下的客厅与厨房细节模块，并替换旧家具和柜体，避免叠放。
- 黑皮沙发改为低矮连续包裹的靠背，奶白沙发改为不对称卧榻；新增薄石托盘茶几、金属管架单椅和小型边几。
- 厨房加入框线门板、黄铜拉手、嵌入厨电、燃气灶、窗架、玻璃门与分层水滴吊灯；水槽台面使用椭圆开孔。
- 灰金石纹增加不规则分叉，木饰面与软包减少橙黄偏色，缩小织物与皮革微纹尺度。所有材质均为原创程序生成。
- 展示架陈设与两幅原创画作各自变化；窗侧柔光补充家具侧面层次。高透射玻璃不进入接触阴影预处理。
- 外景按现场照片增加前后树冠与草岸遮挡，缩小连续开阔水域。窗景仍是近似布景，建筑身份、距离与方向未测绘。
- 调整客厅、厨房与阳台的默认观看方向和俯角，便于进入后观察关键陈设与窗景。

## 0.2 · 2026-10-24

- 细化沙发、桶形扶手椅、黑皮管架单椅、软包床头、枕头和下垂床毯；新增软边与缝线。
- 原创程序 PBR 表达灰金石纹、胡桃木、织物、皮革及鱼骨拼地板，不含照片裁切纹理。

- 增加接触阴影、室内柔光和日光／暖光联动；触屏或低性能设备可关闭额外遮蔽效果。
- 按现场低视点照片推定水岸、树群与远处建筑。俯览隐藏外景，漫游显示。
- 主卧床头不透明墙板按同面积样板间照片修订；窗外方位、距离和建筑身份未实测。
- 构建支持案例顶层的独立 JavaScript 材料或外景模块，统一计算资源版本；原照片不进入发布包。
