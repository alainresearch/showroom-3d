# 证据与还原程度

模型应让浏览者分清已知尺度与设计推定。每个案例在 `metadata.json` 保留公开来源与假设，必要时在 `sources.md` 记录逐项核对过程。

| 信息 | 应如何记录 |
| --- | --- |
| 图纸明确标注 | 写明来源、图号、单位及尺寸链；可逐项复核 |
| 实拍可观察 | 说明对应房间与可见范围；避免由一个角度推断整个房间 |
| 按图推定 | 标记推定墙厚、开口、局部长度及比例依据 |
| 示意设计 | 明确说明家具、材质、灯光或装饰尚无直接证据 |

## 天览 385A，22 栋 01

参考来源：[公开文章及户型图](https://www.sohu.com/a/1007897925_121798391)。图中标注为 22 栋 01、385A；顶部横向尺寸链为 **4100 + 3650 + 3750 + 8400 mm = 19.9 m**。这条尺寸链可以复核整体横向尺度，但不能替代其他方向或局部构造的尺寸核对。

- 室内净高暂定 **3.1 m**，尚待可信资料或现场测量确认。
- 385A 作为户型标识保留；未独立确认产权、建筑或套内面积，也不把横向总尺寸直接换算成面积。
- 未明确标注的墙厚、门窗开口与局部构造按图推定，需逐项补证。
- 家具、材料和灯光包含示意设计，未完成全部对应实拍核对；不能称为完整实景复刻。
- 本模型用于空间理解与交互探索，不作为施工或装修尺寸依据。

## 改进顺序

先核对外轮廓与尺寸链，再核对分隔墙、门窗和房间连接，随后处理净高、家具位置、材质与光线。发现矛盾时同时修正模型和证据说明，保留仍未解决的假设。每次更改尺度后检查行走路径与碰撞，避免视觉看似合理但实际无法通过。
